Asterisks on the bond code carry the instrument type.

  • The PDF appends footnote asterisks to bond codes — those marks classify the instrument.
  • ** = inflation-linked, *** = floating-rate, * = three-maturity (split tranche), **** = repo at all-in price.
  • The loader translates marks into BondSchedule.bond_type: fixed / ilb / frn / sukuk / retail / perpetual / infrastructure / zero.
  • Without the marks, a code like R2044 would look fixed-rate — with *, the loader knows it’s three-maturity.
