GitHub

GitHub Personal Account

Everything starts with github.com/miketrounce, my personal GitHub account. GitHub is where I store and version all my code. Every change is tracked, so there is a complete history of how things have evolved.

I have three repositories. The first, miketrounce.github.io, contains this personal website — the page you are reading right now. GitHub Pages serves it for free at miketrounce.github.io. The second, tricksy, contains the games and experiments. Cloudflare Pages serves it for free at the Tricksy website. The third, techsplainer, is where I write down how I understand technology. GitHub Pages serves it at miketrounce.github.io/techsplainer.

GitHub Organisation

I am the owner of a GitHub Organisation called Knowledge Machines. It's just a personal project at the moment but it might become a company. There's only one repository at the moment, and it contains an index.html file that is the basis for the Knowledge Machines website.

Weak Network

My weak network is essentially my first connections on LinkedIn who are not those whom I'd already count in my strong network; about 10,000 people. The archetype would be someone who:

— focuses on fixed income and FX products (as opposed to equities)

— focuses on simple products (as opposed to complex derivatives)

— pays attention to emerging market economies and financial markets

— uses their discretion (as opposed to systems)

— spends 75% of their time on a computer and 25% talking to people
