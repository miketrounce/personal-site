Online Organisation

How my online presence is set up

GitHub

Everything starts with github.com/miketrounce, my personal GitHub account. GitHub is where I store and version all my code. Every change is tracked, so there is a complete history of how things have evolved.

Repositories

I have two repositories. The first, miketrounce.github.io, contains this website — the page you are reading right now. GitHub Pages serves it for free at miketrounce.github.io.

The second, tricksy, contains the games and experiments. It is hosted on Cloudflare Pages at tricksy.pages.dev.

Knowledge Machines

The dashboards live separately and are hosted on Cloudflare Pages at knowledge-machines.pages.dev. Unlike this website, they are built with React and Vite and connect to live data sources.

How it all connects

The homepage at miketrounce.github.io links out to everything else. It is the single entry point — the place someone goes to understand what I do and how I can help them. From there they can reach the professional page, the dashboards, or the games.
